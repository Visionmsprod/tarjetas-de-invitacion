## 🚀 Cómo publicar en GitHub Pages en 3 pasos:

1. **Crea un repositorio en GitHub:**
   - Entra a [github.com/new](https://github.com/new) y crea un nuevo repositorio público (ejemplo: `invitacion-valeria-sofía`).

2. **Sube los archivos:**
   - Descomprime este archivo ZIP en tu computadora.
   - Sube `index.html` y la carpeta completa `media/` directamente a la raíz de tu repositorio.

3. **Activa GitHub Pages:**
   - En tu repositorio de GitHub, haz clic en **Settings** > **Pages**.
   - En **Source**, selecciona **Deploy from a branch**.
   - En **Branch**, selecciona **main** (o master) y carpeta **/(root)**.
   - Haz clic en **Save**.

En 1 minuto tu invitación estará disponible en:
`https://<tu-usuario>.github.io/<tu-repositorio>/`

¡Todas las fotos y el Sobre Digital funcionarán al 100%!
